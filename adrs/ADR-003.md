# ADR-003: Definição dos Protocolos de Integração (gRPC, REST e RabbitMQ)

- **Status:** Aprovado
- **Data:** 2026-10-20

## Contexto
Há comunicação síncrona (cliente e gateway) e fluxos assíncronos (envio para gráficas, processamento de pedidos).

## Decisão
- **REST/JSON** para a API pública exposta pelo gateway.
- **Mensageria assíncrona (RabbitMQ)** para envio de pedidos de impressão, com fila de mensagens com falha (DLQ).
- **gRPC** apenas para chamadas internas de baixa latência, quando necessário.

## Consequências e Trade-offs
- (+) A mensageria absorve picos e desacopla do sistema legado das gráficas.
- (+) REST é simples e de amplo suporte.
- (-) Operar um broker aumenta a complexidade.
- (-) Consistência eventual no fluxo assíncrono.

## Alternativas consideradas
Tudo síncrono via REST: descartado por não tolerar a lentidão e as falhas das gráficas legadas.
