# ADR-001: Adoção do Estilo Arquitetural (Monólito Modular vs. Microsserviços)

- **Status:** Aprovado
- **Data:** 2026-09-10

## Contexto
O Agile Dead Trees precisa publicar e vender e-books e livros impressos, calcular royalties e oferecer recomendação personalizada por IA. A equipe é pequena (4 pessoas) e o prazo é curto.

## Decisão
Adotar um **Monólito Modular**, com módulos separados por contexto de negócio (catálogo, royalties, agente de IA), expostos por um API Gateway.

## Consequências e Trade-offs
- (+) Deploy e depuração mais simples; menos custo operacional.
- (+) Os módulos podem virar serviços no futuro, porque as fronteiras já existem.
- (-) Escala o conjunto todo, não cada módulo isoladamente.
- (-) Exige disciplina para não criar dependências entre módulos.

## Alternativas consideradas
Microsserviços desde o início: descartado pela complexidade operacional para o tamanho da equipe.
