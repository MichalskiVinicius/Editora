# ADR-005: Seleção de Frameworks, Banco Vetorial e Stack do API Gateway

- **Status:** Aprovado
- **Data:** 2026-11-05

## Contexto
É preciso escolher a stack de execução, o gateway e o armazenamento para a recomendação por IA.

## Decisão
- **Node.js** para a aplicação (server.js, catálogo, royalties, agente de IA).
- **Kong** como API Gateway (configuração declarativa em kong.yml).
- **Docker / Docker Compose** para empacotar e subir o ambiente.
- **Banco vetorial:** [CONFIRMAR qual é usado, ou remover se não houver].

## Consequências e Trade-offs
- (+) Ambiente reproduzível em qualquer máquina.
- (+) Kong centraliza autenticação, limites de requisição e roteamento.
- (-) Mais componentes para configurar e monitorar.
- (-) A equipe precisa dominar Docker e a configuração do Kong.

## Alternativas consideradas
Gateway próprio escrito no código da aplicação: descartado por reinventar recursos prontos.
