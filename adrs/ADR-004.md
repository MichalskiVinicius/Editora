# ADR-004: Mapeamento de Contextos Delimitados e Camada Anti-Corrupção

- **Status:** Aprovado
- **Data:** 2026-10-28

## Contexto
O sistema reúne assuntos distintos (catálogo, royalties, recomendação por IA) e conversa com sistemas legados com modelos de dados próprios.

## Decisão
Definir **Bounded Contexts** separados (Catálogo, Royalties, Recomendação/IA) e proteger o domínio com uma **Camada Anti-Corrupção (ACL)** nas integrações externas, usando adaptadores.
- **Core Domain:** orquestração de publicação híbrida (digital e impressa).
- **Supporting:** royalties e catálogo.
- **Generic:** autenticação e gateway.

## Consequências e Trade-offs
- (+) A linguagem do domínio fica protegida de formatos externos.
- (+) Cada contexto evolui de forma independente.
- (-) Exige tradução entre contextos e mais código de adaptação.

## Alternativas consideradas
Modelo de dados único compartilhado: descartado pelo vazamento de conceitos entre contextos.
