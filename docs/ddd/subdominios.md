\# Classificação dos Subdomínios



| Tipo | Subdomínio | Justificativa |

|---|---|---|

| \*\*Core Domain\*\* | Orquestração da publicação híbrida | É o diferencial do negócio: decidir e coordenar o fluxo de uma obra entre o formato digital (e-book) e o impresso (via gráfica). É onde o investimento em qualidade deve se concentrar. |

| \*\*Supporting\*\* | Gestão do Catálogo | Necessário para a operação, mas não diferencia a editora das concorrentes. |

| \*\*Supporting\*\* | Cálculo de Royalties | Regras próprias da editora, porém de apoio ao negócio principal. |

| \*\*Supporting\*\* | Recomendação personalizada | Agrega valor ao leitor, mas usa um serviço de IA externo e não é o núcleo do negócio. |

| \*\*Generic\*\* | Autenticação e controle de acesso | Problema comum a qualquer sistema; resolvido com o API Gateway (Kong). |

| \*\*Generic\*\* | Processamento de pagamentos | Problema genérico, delegado a um serviço de terceiros. |



\## Observações

\- A classificação segue a ADR-004.
